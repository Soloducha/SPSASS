# Preguntas Frecuentes

## Facturación y Pagos

### ¿Cómo funciona la facturación?

La facturación es **mensual o anual** (con 20% de descuento en anual). Se cobra al inicio de cada período. Los planes pagos se renuevan automáticamente salvo cancelación.

### ¿Qué métodos de pago aceptan?

- Tarjetas de crédito/débito (Visa, Mastercard, Amex) via Stripe
- Transferencia bancaria (solo planes Growth y Enterprise, factura anual)
- PayPal (próximamente)

### ¿Hay contratos de permanencia?

**No.** Puedes cancelar en cualquier momento. El servicio sigue activo hasta el final del período pagado. No hay penalizaciones ni cláusulas de permanencia.

### ¿Puedo cambiar de plan en cualquier momento?

**Sí.** 
- **Upgrade**: Efectivo inmediato, se cobra la diferencia prorrateada.
- **Downgrade**: Efectivo al final del período actual. Recibirás aviso si excedes límites del nuevo plan.

### ¿Qué pasa si excedo los límites de mi plan?

Recibirás alertas al 80%, 90% y 100% del límite. Al alcanzar el 100%:
- **Servidores/API Keys/Reportes**: Se bloquea la creación de nuevos recursos (403)
- **Miembros**: No se pueden invitar más usuarios
- **Retención**: Métricas antiguas se empiezan a purgar según la política del plan

## Agente e Instalación

### ¿El agente consume muchos recursos?

**No.** Diseñado para ser ligero:
- **CPU**: ~1-2% en idle, ~3-5% durante recolección (cada 30s)
- **RAM**: ~15-30 MB
- **Red**: ~50-200 KB/min por servidor
- **Disco**: Logs rotativos (~10 MB/día)

### ¿Funciona en Windows y Linux?

**Sí, nativamente.**
- **Linux**: systemd service (Ubuntu 18.04+, Debian 10+, CentOS/RHEL 7+, Fedora, Alpine)
- **Windows**: NSSM service (Windows Server 2016+, Windows 10/11 Pro/Enterprise)
- **Contenedores**: Docker image disponible (próximamente)

### ¿Necesito abrir puertos de entrada?

**No.** El agente solo hace conexiones **salientes** (HTTPS 443 / HTTP 8000) hacia tu instancia SPSAAS. No requiere puertos abiertos ni VPN.

### ¿Qué métricas recolecta el agente?

**Sistema**: CPU, memoria, disco, red, load average, uptime
**Procesos**: CPU, memoria, hilos, FDs abiertos, estado (systemd)
**Servicios**: Estado, uptime, métricas custom via API
**Jobs**: Ejecuciones, duración, código de salida, output
**Red**: RX/TX bytes, paquetes, errores, drops
**Contenedores**: (Próximamente) Docker/Podman stats

## Seguridad y Privacidad

### ¿Dónde se almacenan mis datos?

- **SaaS (cloud)**: AWS eu-west-1 (Frankfurt) / us-east-1 (Virginia)
- **Enterprise**: Tu VPC, on-premise, o región AWS/GCP/Azure de tu elección
- **Backups**: Diarios, encriptados, retención 30 días (configurable en Enterprise)

### ¿Mis métricas son privadas?

**Sí.**
- Encriptación en tránsito (TLS 1.3) y en reposo (AES-256)
- Aislamiento por tenant (RLS en PostgreSQL + row-level security)
- Tu organización solo ve sus datos
- No vendemos ni compartimos datos con terceros

### ¿Cumplen GDPR / SOC 2 / ISO 27001?

- **GDPR**: Sí, DPA disponible, derecho al olvido, portabilidad
- **SOC 2 Type II**: En proceso (Enterprise)
- **ISO 27001**: En proceso (Enterprise)
- **HIPAA**: BAA disponible (Enterprise)

## API y Desarrollo

### ¿Hay API pública?

**Sí.** API REST completa en `/api/v1/` con:
- OpenAPI 3.0 spec en `/api/openapi.json`
- Swagger UI en `/docs/api`
- SDKs: TypeScript, Python, Go (próximamente)
- Webhooks para eventos en tiempo real

### ¿Hay rate limiting en la API?

**Sí, por plan:**
- Free: 60 req/min
- Starter: 200 req/min
- Growth: 1,000 req/min
- Enterprise: 5,000 req/min

Headers: `X-RateLimit-Limit`, `X-RateLimit-Remaining`, `X-RateLimit-Reset`

### ¿Puedo usar Terraform / Pulumi / Ansible?

**Sí.** Provider Terraform oficial (próximamente), módulos Ansible community, API REST para todo lo demás.
